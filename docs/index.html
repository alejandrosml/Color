Un coup de main ?

Où trouver l’aide dans Color ?

Ouvre Mon dessin, en haut à gauche, puis Aide. Tu y trouveras comment utiliser le pinceau, les formes, les tampons, le texte, la gomme, le pot de peinture et les pages à colorier.

Comment changer d’univers ?

Le bouton Univers change le décor de l’atelier. Double-clique sur un élément du décor pour entendre son nom.

Comment installer Color sur Windows ?

Le badge Microsoft Store télécharge le petit installateur de Color Atelier de Dessin pour Windows 10 et 11. Cette version est signée par Microsoft et se met à jour automatiquement.

Tu peux aussi télécharger la version à dézipper. Cette version portable n’est pas signée. Si Windows affiche « Windows a protégé votre ordinateur » au premier lancement, « Informations complémentaires » puis « Exécuter quand même » permettent de l’ouvrir.

Pour les parents

Color est gratuit, sans compte et sans publicité. L’atelier fonctionne hors ligne et ne collecte aucune donnée.

Dans Mon dessin, les options de l’adulte permettent de simplifier l’interface, de régler les sons, les animations, l’impression et l’accessibilité. Un calcul peut protéger l’accès à ces réglages.
