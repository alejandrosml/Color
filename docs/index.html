Color

Un petit atelier de dessin pour les enfants, sur Mac, iPhone, iPad et Windows : le pinceau, les formes, les tampons, le texte, la gomme, le pot de peinture, des pages à colorier, dix univers à choisir, et le film de ton dessin qui se refait tout seul. Gratuit, sans publicité, sans compte, sans Internet.

Aide

Dans Color, « Mon dessin », en haut à gauche, ouvre l’aide, qui explique chaque outil, et les options de l’adulte — l’interface plus ou moins simple, l’univers et le mouvement de son décor, les sons, l’impression, l’accessibilité ; un calcul peut en garder l’entrée. Le bouton « Univers » change l’habit de l’atelier ; un double-clic sur une chose du décor dit son nom.

Color pour Windows

Pour Windows 10 et 11, Color est dans le Microsoft Store, sous le nom « Color Atelier de Dessin ». Microsoft l’a vérifiée et la signe, et elle se met à jour toute seule.

Le bouton télécharge un petit installateur de Microsoft, qui installe Color. Une version à dézipper, sans installation, reste sur la page des versions de Color ; celle-là n’est pas signée : au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur », comme pour tout programme qu’il ne connaît pas encore. « Informations complémentaires », puis « Exécuter quand même », la lance.
